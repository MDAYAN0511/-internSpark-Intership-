# InternSpark Internship – Data Science Tasks

This repository contains projects and tasks completed during my InternSpark Data Science Internship. The internship focuses on developing practical data science skills through data cleaning, exploratory data analysis (EDA), visualization, and machine learning techniques.

## Project 1: Zomato Dataset Analysis

### Objective

Analyze Zomato restaurant data to identify trends in restaurant ratings, cuisines, pricing, and location preferences, and generate business recommendations.

### Dataset

* Source: Kaggle Zomato Dataset
* Records include restaurant information, ratings, cuisines, locations, reviews, and pricing details.

### Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* WordCloud
* Jupyter Notebook / Google Colab

### Tasks Performed

* Data cleaning and preprocessing
* Handling missing values and duplicates
* Exploratory Data Analysis (EDA)
* Restaurant rating analysis
* Cuisine popularity analysis
* Location hotspot analysis
* Price vs Rating analysis
* Data visualization using charts and heatmaps
* Business recommendations based on insights

### Visualizations

* Rating Distribution
* Top Cuisines Analysis
* Location Hotspots
* Price vs Rating Scatter Plot
* Correlation Heatmap
* Cuisine WordCloud

### Key Findings

* Most restaurants have ratings between 3.5 and 4.5.
* Popular cuisines dominate restaurant listings.
* Certain locations have significantly higher restaurant density.
* Restaurant pricing has a weak correlation with ratings.
* Customer preferences vary by cuisine and location.

### Business Recommendations

1. Promote highly rated restaurants.
2. Improve cuisine-based recommendations.
3. Focus marketing efforts on restaurant hotspots.
4. Utilize customer review insights.
5. Provide pricing benchmarks for restaurant partners.
